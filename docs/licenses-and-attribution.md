# Licenses and Attribution

The full third-party dependency, model, and media license table lives in
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) at the repository
root. This page covers the one licensing decision that needs more than a
table row: **using Ultralytics YOLOv8 (AGPL-3.0) inside a networked
service.**

## The AGPL-3.0 question

The `ultralytics` PyPI package (which provides YOLOv8n) is licensed
AGPL-3.0. AGPL-3.0's distinguishing clause (compared to plain GPL) is that
running a *modified* version of the program and letting users interact
with it over a network counts as "conveying" the program, which triggers
the obligation to offer that modified source.

**This project's position:**

1. `ultralytics` is used as an unmodified dependency, installed from PyPI,
   not vendored or patched.
2. This entire repository -- the actual "program" combined with
   `ultralytics` to form the network service -- is public on GitHub under
   MIT at all times, at the exact commit any deployed instance is running.
3. Therefore, anyone interacting with a deployment of this service can
   already obtain the complete corresponding source (this repo) plus the
   unmodified upstream `ultralytics` source (also public), satisfying
   AGPL-3.0's network-source-availability intent for this specific,
   unmodified-dependency case.

**If you fork this repository:** keep your fork public, or otherwise
ensure users of your deployment can obtain your exact running source, for
as long as you depend on `ultralytics`. If you need a deployment that is
not open-source, either don't expose YOLO-derived inference over a
network, or purchase an
[Ultralytics Enterprise License](https://www.ultralytics.com/license),
which removes the AGPL-3.0 obligation.

## MiDaS (MIT) and everything else

MiDaS_small and every other runtime dependency in this project are
permissively licensed (MIT/BSD/Apache-2.0) and impose no comparable
network-use obligation; see `THIRD_PARTY_NOTICES.md` for the complete
table.
